Mood Atlas · 开始使用

把说不清的不对劲，
变成看得见的轨迹

这是一个记录情绪的网页应用。它没有服务器、也没有后台账号系统 —— 你的记录只存在两个地方：你自己的浏览器，和你自己的 GitHub 私有仓库。

为什么要配 GitHub？
因为没有任何服务器替你保管数据，所以需要你自己准备一个"云端抽屉"。GitHub 的私有仓库免费、稳定、只有你能看，正好合适。全过程大约 3 分钟，只做一次。配完之后手机和电脑就能看到同一份记录。
不想配也可以。跳过下面全部步骤，直接开始记 —— 数据会存在当前这个浏览器里，照样能用。只是换设备、清缓存后会丢，也没法手机电脑同步。

第一部分 · 准备云端抽屉

1

注册一个 GitHub 账号

打开 github.com/signup，用邮箱注册，免费。已经有账号就跳到下一步。

注册完请记住你的用户名（登录后在右上角头像里能看到，形如 your-name）。

2

新建一个私有仓库

仓库就是那个"抽屉"。直接打开 github.com/new，然后：

  1. Repository name 填 mood-atlas-sync（也可以自己取名，但要和后面填进设置里的一致）
  2. 下面选 Private（私有）—— 一定要选这个，否则任何人都能看到你的记录
  3. 勾上 Add a README file
  4. 点绿色按钮 Create repository
建好之后什么都不用管，页面关掉就行。记录会自动以 情绪记录.json 的形式存进去。
3

生成一把只能开这个抽屉的钥匙

网页需要一把"钥匙"（GitHub 叫 access token）才能往仓库里写数据。打开 这个链接 直达创建页（若跳到登录页，登录后再点一次），然后：

  1. Token name 随便填，比如 mood-atlas
  2. Expiration（有效期）选一个长一点的，比如 1 年。到期后重新生成一把换上即可
  3. Repository access 选 Only select repositories，在下拉里勾选刚才建的 mood-atlas-sync
  4. 展开 Permissions → Repository permissions，找到 Contents 这一项，右边下拉改成 Read and write（读写）
  5. 拉到最下点 Generate token，再确认一次
  6. 页面会显示一串以 github_pat_ 开头的长字符 —— 立刻复制下来
注意：这串字符只会完整显示这一次，关掉页面就再也看不到了。先粘到备忘录里存着，或者直接去做第 4 步。万一丢了也不要紧，回来重新生成一把新的就行。

第二部分 · 连上应用

4

在网页里填一次

回到情绪地图页面，点右上角 设置，找到「GitHub 云同步」那一块，确认标签停在 个人空间，然后：

  1. GitHub 用户名：填你的用户名。也可以留空 —— 待会点「测试连接」会自动识别并帮你填好
  2. 私有仓库名：填 mood-atlas-sync（和第 2 步取的名字一致）
  3. 访问令牌：粘贴第 3 步复制的那串字符
  4. 勾上 启用同步 和 保存后自动同步
  5. 点 测试连接，看到"已连上"就成了；再点一次 立即同步
令牌只存在你这台设备的浏览器里，不会上传到任何第三方服务器。它也只能碰你勾选的那一个仓库，别的都动不了。
5

手机上也配一次，就同步了

用手机浏览器打开同一个网址，同样进「设置」，用同一个用户名、同一个仓库名、同一把令牌再填一次。填完就能看到电脑上记过的全部内容了。

顺手可以装成 App：

  • iPhone（Safari）：底部分享按钮 → 添加到主屏幕
  • Android（Chrome）：右上角菜单 → 添加到主屏幕 / 安装应用
"配置一次"不是登录 —— 每台设备、每个浏览器都要各自填一次。填完之后，大家读写的都是云端那同一份数据。

第三部分 · 可选功能

A

让 AI 帮你整理（可选）

应用里的「AI 帮填」可以把你随手写的一段话自动拆成心情、睡眠、标签这些字段，也能在开头给你一句基于历史记录的开场白。这需要一个 DeepSeek 的 API Key：

  1. 去 platform.deepseek.com 注册
  2. 在 API keys 页面创建一个 key，复制
  3. 回到应用「设置 → AI」，粘贴进去
Key 同样只存在你的浏览器里，请求直接从你的设备发给 DeepSeek。用量按 DeepSeek 的计费走，不用也完全不影响记录功能。
B

和朋友共用一份记录（可选）

设置里的「共享空间」是独立的第二套配置，用来和别人共用同一份记录（比如情侣、室友、互相监督的搭子）。做法：

  1. 由其中一个人按第 2、3 步再建一个仓库，比如叫 mood-atlas-shared，并生成一把只勾选这个仓库的令牌
  2. 把「用户名 + 仓库名 + 这把令牌」发给同伴
  3. 各自在设置里切到 共享空间 标签填进去
  4. 每个人填一个昵称（如 🦝 / 🐰），用来区分谁记的
  5. 关键一步：每个人在「我的同步文件」里填不同的文件名，比如一个人填 情绪记录_浣熊.json，另一个填 情绪记录_兔子.json
为什么要填「我的同步文件」？
没填的话，所有人写同一个文件，两个人同时记就会出现"同步冲突"，后写的人覆盖先写的，数据丢失。填了之后，每个人只写自己的文件，读取时自动合并所有人的 —— 既不冲突也不混。
如果你之前没填这一项就在共用：你俩的数据可能已经混在同一个 情绪记录.json 里了。需要：①各自填好「我的同步文件」②点同步，应用会自动把你的记录拆到你自己的文件里 ③旧的混装文件会自动不再合入。

常见问题

我的数据到底存在哪儿？谁能看到？

存在你自己 GitHub 账号下那个私有仓库的 情绪记录.json 里，以及你本机浏览器的缓存里。这个网页本身不带服务器，作者、也包括发你链接的人，都看不到你的记录。

测试连接提示"仓库不存在"？

三个地方对一下：仓库名拼写是否一致、仓库是否真的建好了、以及第 3 步生成令牌时有没有在 Only select repositories 里勾中这个仓库。

提示"令牌无效"？

多半是权限没给够或者已过期。回到令牌页面确认 Contents 是 Read and write；过期的话重新生成一把，粘贴替换即可。

令牌复制的时候弄丢了怎么办？

没影响。回 GitHub 重新生成一把新的，旧的删掉就行。仓库里的数据不会丢。

换手机 / 重装浏览器，记录会没吗？

只要配过同步就不会 —— 新设备上重新填一次那三项，数据会自动从云端拉回来。另外「设置」里也能导出一份 JSON 备份自己收着。

和朋友共用时提示"同步出现冲突（数据在别处被更新）"？

这是因为两个人写同一个文件，后写的和先写的"撞车"了。解决方法：每个人在「共享空间」设置里填好「我的同步文件」（填不同的名字），这样各写各的文件，读取时自动合并，再也不会冲突。

我看到对方/自己的记录里出现了别人的昵称？

这是之前没填「我的同步文件」时，两个人数据混在一起留下的旧记录。填好「我的同步文件」后，点一次同步，新记录就不会再混了。旧记录可以手动删除或忽略。

手机上怎么更新到最新版本？

如果应用装在了主屏幕（PWA），可能还在跑旧版缓存。方法：①打开应用 → 设置 → 拉到最下面看版本号 ②如果版本旧了，长按主屏幕图标删掉重装，或者用浏览器打开网址时强制刷新（Safari 长按刷新 → 请求桌面网站再切回来；Chrome 下拉刷新两次）③也可以在浏览器设置里清除这个网站的缓存后再打开。

当前版本是多少？在哪看？

打开应用 → 设置 → 拉到最底部，会显示一行类似 v45 · 合并近似标签可自定义 · 小绪建议 + 人工编辑 的版本号。如果看不到这行，说明你跑的是很老的版本，需要更新。

同一天记了两次会怎样？

同一天只保留一条，后来填得更完整的那条会覆盖前一条。想改当天的内容，直接再记一笔即可。

时间轴可以评论吗？能回复别人的评论吗？

可以。打开「时间轴」，点任意一条记录展开评论区。评论会显示作者 emoji（如 🐰 / 🦝）和发送时间，同一个人连续发的评论会合并在一起。每条评论右侧都有「回复」，点击即可针对这条评论追加回复，形成楼中楼。共享模式下所有人的评论都会同步，顶栏「情绪地图」右边出现红色提示时说明有新评论。

合并近似标签怎么用，可以自己改吗？

打开「设置 → 合并近似标签」，小绪会先根据现有标签给出合并建议（每组的「标准名 + 别名」）。你可以直接修改：改标准名、给某组加/删别名、删掉不想要的分组，也能点「加一组」自己建一组；觉得不准就点「让小绪重新建议」。确认合并后，别名会统一替换成标准名。该操作只动你自己记录里的标签，不影响对方；个人模式下则处理全部标签。

这份记录只对你自己负责 —— 想记就记，断几天也没关系。它的用处不是打卡，是过一阵子回头看的时候，你能认出自己的规律。
