Mood Atlas · 界面结构与 GitHub 开源组件库对照

共梳理 10 个界面 / 视图，每个界面匹配 1-3 个 GitHub 开源库，并明确交互逻辑。全表优先推荐零依赖、纯原生 JS 的库，与 Mood Atlas 现有技术栈一致。

1 启动屏 全屏动效

PWA 添加到桌面后打开的第一个界面，纯 CSS 动效 + Canvas 粒子，无网络依赖，快速渲染后自动淡出进入看板。当前实现：极光 + 品牌字 + 进度条。

推荐 GitHub 开源库
① splash-screen-js
github.com/andygup/splash-screen-js
⭐ 19 · 仅 1.26KB · 纯 CSS3+JS
100% 框架无关，极简 API（show/hide），适合 PWA 首屏。CSS 可完全自定义，比当前硬编码的启动屏更易维护。
Vanilla JS零依赖MIT
② nanosplash
github.com/isakhauge/nanosplash
⭐ 仅 3KB · TypeScript 支持 · ESM/CJS/IIFE
极轻量加载屏，支持 show/hide FIFO 队列，可嵌入到指定容器内。适合需要"数据加载中"场景，不止是首屏。
Vanilla JS零依赖MIT
③ particles-js
github.com/joseba-mirena/particles-js
⭐ v1.2.0 · 11.8KB min · 多种粒子类型
如果替换当前 Canvas 粒子背景，这个库支持 circle / star / confetti / emoji 四种粒子 + flow / rain / firework 三种动画模式 + 鼠标互动。可替代当前手写的 #bg Canvas。
Vanilla JS零依赖MIT
交互逻辑
① 页面加载 → 显示启动屏（极光 Canvas + 品牌字 CSS 动效 + 进度条）
② 渲染完成 / 3 秒最短展示 → 启动屏 fadeOut（opacity 过渡 0.6s）
③ 兜底机制 → 8 秒硬超时强制移除，绝不卡界面
④ 进入看板 → 触发 IntersectionObserver 逐个 reveal 面板入场动画
2 看板（Dashboard） 数据可视化主视图

核心页面，包含：时间段选择器、Hero 情绪球、概览统计、情绪地形图（SVG 散点）、热力图（13 周）、高频标签云、情绪日历、睡眠图表、精力×紧绷散点图、高峰低谷、未完成打算、今日提问、聊情绪入口。

推荐 GitHub 开源库
① Frappe Charts
github.com/frappe/charts
⭐ 15k+ · 零依赖 · 纯 SVG · 响应式
零依赖纯 SVG 图表库，支持折线图/柱状图/散点图/饼图/热力图。非常适合替换当前手写的情绪地形（SVG scatter）和睡眠图表。API 极简，开箱即用。
Vanilla JS零依赖MIT
② Cal-Heatmap
github.com/wa0x6e/cal-heatmap
⭐ 3.1k · TypeScript · 动画日期导航
GitHub 贡献图风格的日历热力图。支持动画日期导航、时间间隔自定义、多语言、插件系统。可直接替代当前手写的情绪日历（#calGrid），功能远比当前丰富。
TS 编写MIT
③ calendar-heatmap（@goujon）
github.com/dkirwan/calendar-heatmap
⭐ 轻量 · 支持 onClick/onHover · 响应式 auto-size
更轻量的日历热力图替代方案。支持 fitWidth 自适应、tooltip、accessibility、React 绑定（可选）。API 更简洁，比 Cal-Heatmap 更轻。
VanillaMIT
交互逻辑
① 时间段选择 → 全部/按年/按月/按日 四个按钮切换，切换后触发全仪表盘重渲染（emotion terrain + heatmap + calendar + stats）
② Hero 区 → 情绪球（#orb）实时显示最近一条记录的心情值；点击"今日一问"展开作答模态框 → 写完后"落到地图"存储并刷新
③ 概览统计 → 展示记录天数、平均心情、高频标签等，数据来自 DATA.records 聚合计算
④ 情绪地形 → SVG 散点图（近 30 天），"我们/自己" toggle 切换视角；点数据点 → 跳转编辑该条记录
⑤ 热力图 + 标签云 → 同一行并排；点标签 → 跳到「历史」视图并筛选该标签
⑥ 情绪日历 → 月份导航（‹ ›），点击有记录的日期 → 弹出当日记录选择窗 → 查看/编辑
⑦ 睡眠 + 精力紧绷 → 日均/月均/年均/自定义周期切换，数据联动更新
⑧ 提问区 → "AI 生成追问"按钮 → DeepSeek API 生成新问题；点问题卡片 → 作答模态框
⑨ 底部"记一笔"FAB → 右下角浮动按钮，可拖拽移动位置，单击（无拖拽）→ 打开聊情绪弹窗
3 记一笔 表单弹窗

全功能记录编辑弹窗。支持：随手写 + AI 帮填 → 结构化表单（日期/时间/心情/睡眠/精力/紧绷/场景/标签/身体信号/行为/备注/重要事件/原因）。

推荐 GitHub 开源库
① settings-ui
github.com/TimoBechtel/settings-ui
⭐ JSON 模板驱动 · 数据绑定 · 可扩展插件
用 JSON 模板自动生成表单 UI + 数据绑定。支持 number/text/boolean/selection/radio 等类型。如果想把"记一笔"的表单字段抽象成配置驱动，这个库可以省去大量手写 HTML。
Vanilla JSMIT
交互逻辑
① 打开方式 → 顶部"记一笔"按钮 / 每日提醒"记一笔" / 日历点击日期（编辑模式）
② 随手写（可选） → 先自由输入 → "让 AI 帮你整理填写"按钮 → DeepSeek 解析为结构化字段 → 回填到下方表单
③ 心情选择 → 1-5 五个按钮，点击高亮，默认 3，必填
④ 原因选择 → 想做但没做/人际/压力/身体/其他 → 选"想做但没做"时展开意图+权重子表单
⑤ 落到地图 → 保存到 localStorage → 触发自动同步到 GitHub（如启用）→ 关闭弹窗 → 刷新看板
⑥ 编辑模式 → 带已有数据打开，显示"删除此条"按钮；修改后保存会覆盖原记录
4 AI 帮填 对话式整理

独立弹窗，用户随便写一段话 → AI 理解后以对话方式追问澄清 → 最终整理成结构化记录 → 用户确认后回填到"记一笔"表单。

交互逻辑
① 用户输入自由文本 → "让 AI 理解一下"按钮 → 发送到 DeepSeek API
② AI 返回理解结果 → 以聊天气泡展示（.xbubble.ai），可能包含追问（如"你提到的胸口闷，是紧张还是身体不舒服？"）
③ 用户回复追问 → 继续对话式交互，直到 AI 认为信息足够
④ AI 输出结构化 JSON → 展示提取到的 mood/scene/tags/sleep/energy/tension 等字段
⑤ 用户确认 → 点击"确认并填入"→ 回填到"记一笔"表单 → 用户可再修改 → 保存
5 聊情绪 AI 聊天窗

DeepSeek 直连 AI 对话窗。结合用户过往记录温柔回应，聊完可一键记一笔。支持"问数据"模式直接查询统计。

推荐 GitHub 开源库
① KleanChat-lite
github.com/medhavisahgal/KleanChat-lite
⭐ 零依赖 · 纯 HTML/CSS/JS · 移动响应式
极简聊天界面模板，纯原生实现，结构清晰。可作为聊情绪 UI 重构的基础骨架。
Vanilla JS零依赖MIT
② Ultralytics LLM Chat Widget
github.com/ultralytics/llm
⭐ 零依赖 · SSE 流式 · 暗色模式 · WCAG 无障碍
生产级 AI 对话组件。支持 SSE 流式输出（DeepSeek 兼容）、暗色/浅色自动切换、移动端全屏、键盘导航。如果未来想让聊情绪支持流式响应，这个库非常合适。
Vanilla JS零依赖MIT
交互逻辑
① 打开方式 → 看板"打开聊情绪"按钮 / 右下角 FAB / 顶部"AI 帮填"按钮 / 键盘快捷键
② 发送消息 → 文本输入 → Enter/Ctrl+Enter 发送 → DeepSeek API 请求 → 加载动画 → 显示 AI 回复
③ 上下文注入 → 发送时将最近 30 条记录摘要作为 system prompt 注入，让 AI 结合历史回应
④ 问数据模式 → 点击"问数据"切换 → 发送时额外注入统计摘要（平均心情、趋势、高频标签等）
⑤ 结束对话 → AI 判断聊到情绪可记录时显示"记一笔"提示条 → 点击提取对话内容生成记录 → 回填到"记一笔"表单
6 时间轴 时间线列表 + 情绪洞察

底部导航第二个视图。垂直时间线展示所有记录，重要事件高亮。顶部含情绪洞察面板（AI 观察/profile、来源分析、维度相关性、AI 解读）。

推荐 GitHub 开源库
① timelined
github.com/Ondreas/timelined

纯 CSS 垂直时间线组件。支持左右交替、统一右对齐、折叠模式、箭头装饰、Font Awesome 图标。用纯 CSS 实现视觉效果，符合 Mood Atlas 的 Vanilla 哲学。可替代当前手写的时间轴样式。
零 JSMIT
② leigh90/timeline
github.com/leigh90/timeline
⭐ 支持水平和垂直 · 响应式 · data-attribute 配置
纯 JS 水平/垂直双模式时间线。支持 data-attributes 配置（不需要写 JS）、响应式断点、滚动触发动画。适合需要水平时间线的场景。
Vanilla JSMIT
交互逻辑
① 日期跳转 → 输入框选择日期 → 滚动到对应时间轴位置
② 情绪洞察面板 → 可折叠（收起/展开）· 我们/自己 toggle 切换视角
③ 来源分析·标签 → 展示每个标签对应的平均心情和记录数
④ 来源分析·场景 → 展示每个场景对应的平均心情和记录数
⑤ 维度相关性 → 计算睡眠-心情、精力-心情、紧绷-心情的相关系数
⑥ "让 AI 解读" → DeepSeek API → 输出自然语言解读
⑦ 时间轴条目 → 带"重要"标记的条目高亮显示 · 点击条目 → 打开编辑弹窗
⑧ 图例 → 显示各署名作者的颜色映射
7 历史记录 + 标签关系图 搜索筛选 + 节点网络

底部导航第三个视图。顶部搜索栏 + 标签筛选 + 心情芯片；中间 Obsidian 风格标签关系图（SVG force-directed）；底部历史列表。

推荐 GitHub 开源库（节点网络图）
① d3-force（D3.js 子模块）
github.com/d3/d3-force
⭐ D3 内置 · 力导向布局 · 业界标准
当前标签关系图手写了力导向算法。d3-force 是业界标准的力布局引擎，支持碰撞检测、link force、多体力等。引入 D3 的 force 模块可以大大简化现有 ~200 行手写力布局代码。
Vanilla JSMIT
② svg3dtagcloud
github.com/Appigle/svg3dtagcloud
⭐ 3D 标签云 · 自定义颜色 · 支持文本+图片
如果想把标签云（#tags）做成 3D 球体旋转效果，这个库提供开箱即用的 SVG 3D 标签云。支持自定义颜色、字体大小、旋转速度。比当前平面标签云更有视觉冲击力。
Vanilla JSMIT
交互逻辑
① 搜索 → 输入框实时筛选：匹配场景/备注/标签/原因字段
② 标签筛选 → 点击"全部标签"→ 底部弹层（.sheet）展开 → 多选标签 → 关闭弹层 → 列表和关系图同步筛选
③ 心情芯片 → 点击 1/2/3/4/5 → 高亮选中的心情等级 → 仅显示该等级的记录
④ 标签关系图 → SVG 力导向布局，可拖拽平移/滚轮缩放 · 点节点 → 筛选该标签的记录 · "整理标签" → 重置布局
⑤ 历史列表 → 每项含日期/心情/标签/备注 · 点击 → 打开编辑弹窗
⑥ "生成 AI 总结" → 打开独立模态框 → 选择时间范围 → DeepSeek 生成文字总结 → 可导出 PDF
8 回收站 独立页

整屏独立页面（.page），从底部导航进入。展示被软删除的记录，可从云端回收站文件拉取、恢复或彻底删除。

交互逻辑
① 进入 → 底部导航"回收站"→ 整屏 slide up 过渡 → 自动从 GitHub 拉取回收站文件
② 列表展示 → 每条显示心情图标/日期/场景/备注/标签
③ 恢复 → 从回收站移除 → 加回主记录列表 → 同步到云端
④ 彻底删除 → 从回收站移除 → 加入 trashPurged 标记 → 云端回收站同步删除
⑤ 清空回收站 → 全部彻底删除，云端同步
⑥ 返回 → 左上角返回按钮 → 回到之前的视图
9 设置面板 配置弹窗

全功能设置弹窗，分三大块：DeepSeek API 配置（Key/模型/路由）、GitHub 云同步（个人/共享空间/令牌/文件隔离）、数据备份（导出 JSON/CSV/导入/清缓存/AI 分类）。

推荐 GitHub 开源库
① settings-ui
github.com/TimoBechtel/settings-ui
⭐ JSON 模板 → 自动生成表单 + 数据绑定 + onChange 回调
如果想把设置面板改成配置驱动，这个库用 JSON schema 自动生成表单 UI，支持 section 分组、数据绑定、change listener。但需要评估迁移成本，当前手写的设置面板已经比较完善。
Vanilla JSMIT
交互逻辑
① DeepSeek 配置 → Key 输入（密码框+眼睛图标切换显示/隐藏）→ "测试"按钮验证连接 → 模型选择（智能路由/手动）→ 手动模式下选模型
② GitHub 同步 → 个人/共享空间分段切换 → 启用同步+自动同步开关 → 输入用户名/仓库名/令牌（密码框）→ "测试连接"验证（独立浮层弹窗显示结果）→ "立即同步"推数据 → "保存设置"落 localStorage
③ 文件隔离 → 共享空间下显示"我的同步文件"输入框 → 多人各自写不同文件避免 409 冲突
④ 数据备份 → 导出 JSON（下载文件）/ 导出 CSV / 导入（文件选择器）/ 清空缓存
⑤ AI 分类 → "立即分类" → DeepSeek 分析所有记录 → 自动打标签 → "合并近似标签"去重
⑥ 所有设置保存 → "保存设置"按钮统一写 localStorage → 成功后弹窗确认（ghTestAlert）
10 主题面板 色板切换

侧滑面板（.theme-panel），14 套预置色板 + 自定义颜色选择器 + 深色/浅色切换。所有颜色由 JS derivePalette() 从单一主题色实时派生。

交互逻辑
① 打开 → 顶部"主题"按钮 → 侧滑面板从右滑入 + 背景遮罩（#scrim）
② 色板选择 → 14 个颜色圆点（.swatch），点击 → derivePalette() 实时计算全部语义色 → 注入 CSS 变量 → 全页面即时变色
③ 自定义颜色 → HTML color input → 选择后同样触发 derivePalette()
④ 深色/浅色 → 两个按钮 → 切换 data-theme="light" 属性 → CSS 变量全面更新
⑤ 关闭 → 点击遮罩 / 再次点"主题"按钮 → 面板滑出
