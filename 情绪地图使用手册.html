把说不清的不对劲，变成看得见的轨迹。这本手册列清楚现在能做什么、怎么点，以及哪些能力还在路上——方便你随时对照「我们已经实现了什么、还差什么」。

01 怎么开始

装好、记下第一笔，就进入正循环。

添加到桌面（PWA）已实现

在手机/电脑浏览器里打开应用后，用浏览器的「添加到主屏幕 / 安装」功能，就能像原生 App 一样从桌面图标启动。

怎么用：手机端一般在浏览器分享菜单里选「添加到主屏幕」；电脑端 Chrome/Edge 地址栏右侧有「安装」图标。安装后用桌面图标打开即是独立窗口。

启动屏（开屏动画）已实现

从桌面图标点开时，会先出现一个带能量球呼吸脉冲、涟漪扩散环、流光进度条的开屏界面，应用名用 Outfit 字体显示，解决早期「系统默认字体、无动效」的粗糙感。

说明：开屏最短展示约 0.65 秒后自动淡出；系统开启「减少动态效果」时动画会自动关闭。背景色已对齐应用深色，消除闪跳。

记录第一笔已实现

点右上角「记一笔」（电脑端）或右下角「+」（手机/电脑都在）开始记录。

怎么用：选心情 1–5、补精力/紧绷/睡眠、写场景与备注，保存即可。所有字段都可留空，先记心情也行。

02 记一笔

一条记录 = 心情 + 可选维度 + 可选「触发原因」。

基础记录字段已实现

心情（必填 1–5）、精力、紧绷、睡眠时长、场景、标签、备注。底部还有「随手写」框，边写边由 DeepSeek 给出结构化建议（填了 Key 后）。

怎么用：直接手填，或先在随手写里用大白话描述，AI 会建议如何归类，确认后填入表单。

触发原因（含「想做但没做」）已实现

记一笔里有一行可选标签：想做但没做 / 人际 / 压力 / 身体 / 其他。选「想做但没做」会展开小区域，让你填具体事项 + 重要程度（轻/中/重）。

怎么用：比如起了「去跑步」的念头却没去，就选「想做但没做」→ 填「去跑步」→ 重要程度选「中」。这条之后会出现在「情绪洞察 · 未完成的打算」里。
cause / intent / intentWeight

AI 聊完自动询问是否记一笔已实现

设置里有开关「AI 聊完自动询问是否记一笔」（默认开）。聊完情绪后，AI 会问你要不要把它整理成一笔记录。

位置：⚙ 设置 → 同步与模型 → 该开关。关掉则聊完不弹询问。

03 看板总览

一屏看完你的情绪地形与节律。

情绪地形（近 30 天）已实现

把近期记录连成一条「地形线」：起点是你最早记的那笔，终点是此刻；沿途地标标出明显起伏，鼠标悬停有提示。手机端线条加粗、标记更醒目。

怎么用：看板顶部即是。配合右上角「自己 / 共同」切换，看自己一个人的轨迹，或所有人的汇总。

我们 / 自己 切换已实现

多人共用一份数据时，所有带切换控件的区块（地形、热力图、标签、高峰等）共用一个「自己 / 共同」状态。

怎么用：任意区块的「自己/共同」开关一点，整个看板同步切换。选「自己」只看你署名的数据。

标签关系图（可平移缩放）已实现

常用标签之间的关系网，节点越大表示出现越多；支持拖动平移、滚轮缩放，并带大标题与整理按钮。

怎么用：看板「标签」卡片里。拖动画布移动、滚轮放大缩小，便于看清哪些标签常一起出现。

平稳光球（背景氛围）已实现

看板背景有缓慢漂浮的柔光球（极光），营造「平稳、不被打扰」的氛围，不抢内容。

说明：浅色主题下自动减弱；开启「减少动态效果」时停止动画。

平均心情 / 睡眠卡片、热力图、高峰已实现

看板含平均心情、平均睡眠等统计卡、按日期的心情热力图、以及情绪「高峰」卡片。

怎么用：高峰卡片同样支持「自己/共同」切换；热力图悬停看某天均值与笔数。

04 情绪洞察

在时间轴（足迹）视图里，把模式显形。

未完成的打算（想做却没做）已实现

自动汇总所有「想做但没做」的记录（近 14 条、没做的排前面），每条显示事项 + 重要度徽章（轻/中/重）+ 状态，并可一键「我做了」标记完成、变灰沉淀，形成闭环。

怎么用：时间轴视图 → 情绪洞察区最顶部。点「我做了」即闭环；AI 解读也会把反复卡住的事编进总结。
intentDone

AI 解读（让 AI 解读）已实现

点「让 AI 解读」，会把来源分析、维度相关性、未完成的打算总结发给 DeepSeek，生成一段 160 字内的温和解读：哪些来源最滋养/最消耗你、睡眠精力与心情的关系、反复想做没做如何消耗你。

前提：⚙ 设置里填了 DeepSeek API Key。无 Key 时按钮会提示去填。

来源分析 / 维度相关性已实现

自动统计哪些标签/场景最滋养或最消耗你，以及睡眠、精力、紧绷与心情的相关性，喂给 AI 做解读。

05 聊情绪与 AI 帮记

用大白话和 AI 聊，它帮你理清、归类、记录。

聊情绪（AI 对话）已实现

看板最底部有「AI 对话 · 用 DeepSeek 聊情绪」区块，可自由倾诉；还有「问数据」按钮，基于你的记录提问。

怎么用：右下角「+」会直接滚到这个对话区并聚焦输入框（电脑/手机都如此）。对话由 DeepSeek 直连，Key 仅存本机。

AI 帮记一笔（对话式提取）已实现

在记一笔弹窗里用大白话描述状态，AI 会追问几个问题以更准确归类，确认后自动填入心情/精力/标签等字段，你点「采用」即可保存。

怎么用：记一笔弹窗里有「AI 帮记」入口；同一轮对话里 AI 会记住你刚说的几句，能顺着追问。

06 回顾与时间轴

按年/月/日回看，去重后不重复。

平均心情 / 睡眠 详情已实现

电脑端点平均心情/睡眠卡片可展开详情；手机端用详情弹层替代「导出 PDF」。

怎么用：看板统计卡点击展开，看分布与明细。

全部标签 底部弹层已实现

时间轴/回顾里「全部标签」用底部弹层选择，方便手机单手操作。

历史去重已实现

记录按稳定 id 合并，再按「日期+时间+记录人+心情+场景+备注」内容指纹去重，避免同一笔出现在两处或跨设备重复。

睡眠周期切换已实现

睡眠图支持按起止时间切换周期范围，看不同时段的睡眠与心情关系。

07 同步与设置

数据在你手里，手机电脑同一份。

GitHub 云同步已实现

配置 GitHub 令牌后，数据自动同步到你指定的私有仓库，手机/电脑共用一份。含离线自动重试、限流排队、多设备冲突自动重试，本地数据不会丢。

怎么用：⚙ 设置 → 填入令牌（需 Contents 读写权限）+ 用户名 + 仓库名；可开「保存后自动同步」。

回收站（恢复 / 彻底删除）已实现

删除的记录进回收站，可恢复；彻底删除按钮已修复（早期因旧记录缺 id 会静默失败，现已按内容指纹兜底）。

怎么用：底部导航「回收站」→ 恢复 / 彻底删除。

主题 / 调色板 / 字体 / 模型路由已实现

深/浅主题、多套调色板、字体切换、DeepSeek 模型与智能路由（闲聊走 Flash、复杂反思走 Pro 深推理）均在设置里可调。

导出 / 导入 JSON 备份已实现

设置里可导出当前数据为 JSON 备份，也可导入恢复。

08 手机端 vs 电脑端

同一套功能，按屏幕自适应交互。

右下角「+」双端常驻已实现

电脑端和手机端都常驻右下角「+」，点它 = 聊情绪（滚到对话区并聚焦）；「记一笔」在顶部按钮，两个入口不重复。

移动端隐藏 PDF / 时间栏已实现

窄屏（≤760px）下自动隐藏「导出 PDF / 时间栏」等桌面向元素，改用底部导航与详情弹层，避免拥挤。

底部导航（手机端）已实现

手机端用底部导航切换 看板 / 时间轴 / 历史 / 回收站；「+」悬浮在导航之上不遮挡。

地形图手机端加粗已实现

已修复早期回归：手机端地形主线加粗、标记描边加粗、文字放大，确保小屏清晰可读。

09 原规划项 · 现已全部落地

以下 5 项曾列在规划中，已在 2026-08-09 全部实现。对应功能在 deploy/index.html 已落地并校验。

跨会话个人画像（让 AI 越来越懂你）已实现

看板时间轴的「情绪洞察」里新增「关于你 · AI 观察到的」卡片：随你记的笔数自动累积观察（总记录数、平均心情、最消耗你的标签、反复「想做却没做」的事、睡眠与心情关系、一周里哪天最低）。每次「让 AI 解读」都会带上这份长期观察，你记的越多，AI 越懂你。

「我做了」可撤销已实现

「未完成的打算」里点「我做了」即闭环变灰；现在每条多了一个「撤销」按钮，误点可一键恢复为未完成。

聊情绪 真·独立小弹窗已实现

右下角「+」与看板的「打开聊情绪」都会弹出独立的聊情绪浮层（非滚动定位），可点 × / 点遮罩 / 按 Esc 关闭。手机电脑通用。

未完成的打算 移到看板首页已实现

「未完成的打算」已从时间轴的情绪洞察移到看板首页（更显眼），点「我做了」闭环、可撤销；情绪洞察里仍保留 AI 解读与「关于你」的汇总。

数据导出增强 / 多空间管理已实现

设置里在原有「导出 JSON」外新增「导出表格（CSV，Excel 友好）」。同时新增「空间管理」：可新建 / 切换 / 重命名 / 删除多个空间（如工作 / 生活），各空间本地数据独立保存。说明：多空间为本地优先，云同步会跟随当前激活的空间——切换空间并同步会改写云端该文件，建议同一空间内保持同步。

10 数据隐私

你的数据在你手里。
· 记录存在浏览器本机（localStorage）+ 你自己的 GitHub 私有仓库。
· DeepSeek API Key 只存本机，不上传任何服务器。
· AI 每次只看到你发过去的文字摘要（来源分析/相关性/未完成的打算），不会上传全部原始数据到第三方。
· 云同步失败、限流、冲突都有兜底重试，本地数据不会因网络问题丢失。

对应代码位置：deploy/index.html 的 ghSync（同步）、callDeepSeek（AI 直连）、insightAiSummary（洞察摘要）、dsKey（Key 仅本机）。
