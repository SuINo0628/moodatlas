## 常见 GitHub PUT contents 错误码映射（以后直接查）
- 401/403 = 令牌无效或没 Contents 读写权限 / 令牌没勾这个仓库
- 404 = 仓库名拼错 / 用户拼错 / 私有仓库没带令牌
- 409 = sha 冲突（并发推送），现已用互斥锁 + retry 处理
- 422 = 内容拒收（sha 与文件状态不匹配，多半网页端动过文件 / 多端并发）
- 429 = 触发 GitHub API 限流（免费账号每小时 5000 次，个人用极少触）
- Failed to fetch = 网络/CORS（https 来源不该出现）
